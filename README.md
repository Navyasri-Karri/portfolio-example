# 🌐 Personal Portfolio Website

## Overview

This is a responsive personal portfolio website developed to showcase education, technical skills, projects, and contact information. The website provides a simple and user-friendly interface to present profile and demonstrate my front-end web development skills.

---

## Features

* 🏠 Home page introducing my profile
* 👤 About Me section
* 💻 Technical Skills
* 📂 Projects showcase
* 📞 Contact section
* 📱 Responsive design using CSS Media Queries
* 🎨 Clean and modern user interface

---

## Technologies Used

* HTML5
* CSS3
* JavaScript

---

## Project Structure

```text
├── index.html
├── style.css
├── script.js
└── images/
```

---

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

No additional installation or setup is required.
